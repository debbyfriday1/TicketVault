# TicketVault - Event Ticket Management Platform

A blockchain-based platform for creating, managing, and trading event tickets as NFTs, preventing fraud and enabling secure resale markets.

## Features
- Create tamper-proof event tickets as NFTs
- Secure ticket trading and resale
- Fraud prevention through blockchain verification
- Organizer royalty system

## Usage
Event organizers use `create-ticket` to issue tickets, attendees use `purchase-ticket` for secure ticket acquisition and trading.
